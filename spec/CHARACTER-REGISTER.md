## Preservation rules
1. All 30 entries belong to Luo.
2. Preserve original handwritten designs exactly.
3. Never replace them with ordinary English letters or approximate Unicode symbols.
4. Each character must eventually have its own digital glyph and unique computer code.
5. The original handwritten reference image is authoritative.
6. Characters must be usable for typing, writing, displaying, and programming.
7. Luo's programming language must use Luo's own characters and syntax.
8. Do not invent pronunciations, meanings, or translations without creator approval.
9. LUO-030 is the creator-confirmed bold crossed X, not an accidental scribble.

For each character, the eventual asset set should include an archival reference, editable vector master, font glyph and stable identifier, creator review status, and tests for rendering, input, serialization, and round-trip text handling. No placeholder drawing is accepted as a final glyph. Add the original reference image before vectorization.
