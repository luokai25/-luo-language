# Luo glyph assets

This directory is reserved for the creator-approved native glyph assets.

The extraction pipeline and per-character source-crop manifest are defined in:
- [Glyph asset pipeline](../spec/GLYPH-ASSET-PIPELINE.md)
- [Extraction tool](../tools/extract_glyphs.py)

Do not commit reconstructed, generated, or traced glyph artwork as an approved
master until the creator has reviewed it against the original handwritten sheet.
The stable IDs are LUO-001 through LUO-030 in the creator's original order.
